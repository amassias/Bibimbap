# Bibimbap 0.1.1

## What changed

- Added the dedicated 8K wireless receiver illustration to the Power & Receiver page.
- Made Dark, Light, and System appearance changes apply immediately.
- Added continuous wireless signal refresh without replacing pending draft settings.
- Serialized HID request/response transactions so signal polling cannot collide with a
  write or another command.

## Distribution

- Versioned ZIP and DMG packages are generated from the tagged source commit.
- Each package includes a manifest and SHA-256 checksums.
- Developer ID signing and notarization depend on the configured GitHub Actions secrets;
  the manifest records the actual signature and notarization state.

## Validation

- Full Swift test suite: 224 tests in 32 suites passed.
- Release build, code-signature verification, and receiver resource embedding passed.
- The signal-refresh behavior is simulator-validated; physical out-of-range testing is
  still a manual hardware scenario.
