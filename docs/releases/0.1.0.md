# Bibimbap 0.1.0

## Distribution

- Versioned ZIP and DMG packages are generated from the tagged source commit.
- Each package includes a manifest and SHA-256 checksums.
- Developer ID signing and notarization are conditional on valid GitHub Actions
  secrets; absent secrets produce an explicitly unsigned artifact.
- The release page links to the same artifacts emitted by the packaging job.

## Validation scope

- The embedded catalog declares 31 families and 127 model identifiers.
- Deterministic simulator tests cover nominal HID/protocol flows, injected failures,
  write read-back and rollback-related error paths.
- The X2 CrazyLight fixture covers CID 87 / MID 10, firmware `v3.05`, and a wired
  connection snapshot.
- No GitHub Actions job has physical mouse hardware. The repository's historical
  physical evidence is listed separately in [`docs/validation-matrix.md`](../validation-matrix.md)
  and is not enlarged by a green build.
- Wireless polling above 1 kHz remains outside the physically validated scope.

## Installation note

Use the checksum file before opening an archive. Follow
[`docs/distribution.md`](../distribution.md) for Input Monitoring permission and for
the distinction between signed release assets and unsigned test packages.
