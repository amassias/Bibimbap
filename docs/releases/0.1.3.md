# Bibimbap 0.1.3

Version 0.1.2 was tagged but not published: package verification found an incomplete
ad-hoc bundle signature. Version 0.1.3 fixes packaging before public distribution.

## What changed

- Seal the complete application bundle with an ad-hoc signature when no Developer ID
  is configured, and verify the signature after extracting the release ZIP.
- Remember the sidebar width between launches, with safe limits for invalid saved values.
- Keep pending changes, their details, and Apply/Revert available from Settings.
- Show synchronization status and explain why menu-bar quick actions are unavailable.
- Block direct quick actions before changing the draft when disconnected, recovering a
  conflict, or waiting for an explicit hardware re-read.
- Add English and French translations for the new menu-bar messages.
- Include the layout, wireless status, localization, and visibility-aware radio polling
  fixes merged since 0.1.1.

## Download and installation

For Apple silicon Macs running macOS 15 or later, download
`Bibimbap-0.1.3-arm64.dmg`, open it, and drag Bibimbap into Applications.
Quit the previous version before replacing it. The ZIP contains the same application.

This release has no Developer ID signature and is not notarized by Apple. Check the
attached manifest and `SHA256SUMS` for the exact package metadata. macOS may require
explicit approval on first launch; see the [installation guide](https://github.com/amassias/Bibimbap/blob/v0.1.3/docs/distribution.md).

## Validation

- Full local Swift suite: 240 tests in 35 suites passed.
- Swift tests cover sidebar preference persistence, allowed quick actions, and blocked
  actions during pending edits, disconnection, conflicts, and uncertain hardware state.
- Distribution checks validate the ZIP, DMG, manifest, and SHA-256 checksums.
- Interface checks used a simulated mouse. No new physical hardware validation is
  claimed for this release; the existing validation matrix remains applicable.
